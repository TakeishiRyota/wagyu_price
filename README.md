# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？
- リモートリポジトリはGitHub上に存在するリポジトリであり、ローカルリポジトリは現在作業しているPC上のリポジトリ。


## プッシュとマージの違いは何でしょうか？
- プッシュはローカルリポジトリの内容をリモートリポジトリに送信することで、マージは他ブランチの変更内容を対象ブランチに適用する。


## コミットとプッシュの違い
- コミットは変更内容をステージングする作業で、プッシュはステージング内容をGithub上に送る。


## コミットのメッセージはどのように書いてあげるのが最適でしょうか？
- 変更内容を短く簡潔にわかりやすく記述する。


## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？
- ローカルでマージする場合は、プッシュされた内容をターミナル上でマージし、プルリクエストはGitHub上でマージする。


## コンフリクトを起こしてしまった場合、どう対処すべきですか？
- コンフリクトの発生個所を確認し、記述理由を加味しながら、仕様に沿ったほうをマージする。
